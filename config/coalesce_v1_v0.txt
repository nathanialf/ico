# output gains one extra instruction. Some original ICO functions kept
# the value in $v0 throughout — same operation, different bytes.
#

# redundant `move $2, $3` and renames $3 → $2 within the function. Safe
# because the move is the only remaining use of $3 after the simplification
# and the global is small enough that no other lifetime conflicts arise.
#
