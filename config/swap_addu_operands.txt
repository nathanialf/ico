# Per-file post-process: swap the operand pair on a commutative `addu` so
# its rd-register lands in the `rs` slot rather than `rt`.
#
# Background: ee-gcc 2.9-991111 canonicalizes `dst = rhs + dst` to emit
# `addu $dst, $rhs, $dst` (rt == rd). The original ICO codegen for some
# functions has the equivalent `addu $dst, $dst, $rhs` (rs == rd). Both
# encode `dst += rhs` semantically, but the bytes differ. Other functions
# in the same project legitimately use the rt==rd form (e.g. the
# DEFINE_LA_INDEXED_ARG_MULT cluster in 02FE08, 0E8BD8, 158C38, ...).
#
# This file lists the file_offs (uppercase hex basename) that need the
# rewrite. The Makefile applies a targeted sed on the .s output for those
# files only. Files not listed are left alone.
#
# Format: <FILE_OFF_HEX> [# optional comment]
# Lines starting with # are comments; blank lines ignored.
