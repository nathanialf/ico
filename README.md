# ico

A clean-room decompilation of the PlayStation 2 game **ICO** (US release,
SLUS-20218, 2001, Sony Computer Entertainment / Team Ico).

The goal is to produce original source code that, compiled with the original
build chain, reproduces a byte-for-byte identical EE-side ELF. No disc data
or extracted assets ship with this repository — you must legally supply your
own disc image to build.

## Quickstart

```sh
./tools/setup.sh                    # idempotent: venv, submodules, EE toolchain, ghidra
cp "/path/to/Ico (USA).bin"  baserom/Ico_USA.bin
cp "/path/to/Ico (USA).cue"  baserom/Ico_USA.cue
./tools/extract_elf.sh              # produces baserom/baseelf.elf and records its SHA-1
make setup                          # runs splat → emits asm/, config/ico.us.ld
make                                # links → build/baseelf.elf → SHA-1 verify
```

The build refuses to proceed unless the SHA-1 of the extracted ELF matches
the value committed to `config/sha1sums.txt`.

## Layout

```
config/        splat yaml, linker script, symbol files, ELF SHA-1
src/           decompiled C
include/       headers (vendored ps2sdk + project-defined types)
asm/           splat output (gitignored except asm/nonmatchings/)
lib/           submodules (splat, asm-differ, decomp-permuter, m2c)
tools/         build orchestration + analysis scripts
decomp/        agent-facing prompts and pattern catalog
docs/          contributor docs (BUILDING, LEGAL, MATCHING_NOTES, PROGRESS)
tough_nuts/    parking lot for deferred near-misses
baserom/       local-only: user's disc + extracted ELF (gitignored)
```

## Reference decomps

Two decomps we cross-reference regularly while working on ICO (read for
technique, never copy code from):

- [`parappadev/parappa2`](https://github.com/parappadev/parappa2) — Sony
  Japan Studio, PS2 2001, **same `ee-gcc 2.9-991111-01` toolchain as
  ICO**. Useful for compiler idioms, header / macro patterns, and the
  per-TU section linking approach we adopt via `slinky`. See
  `decomp/NOTES.md` for specific cross-references.
- [`zeldaret/oot`](https://github.com/zeldaret/oot) — Ocarina of Time,
  N64. The decomp workflow this project structurally models on: splat-
  driven yaml, asm-differ, decomp-permuter, per-function matching loop.
