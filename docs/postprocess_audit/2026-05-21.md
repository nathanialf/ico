## Key pattern learned

C-source can coax **mid-function scheduler nudges**:
- commutative ops via inline asm `+r` (ADDU_RT)
- paired stores via volatile cast
- goto-fused returns
- delay-slot fills via source restructuring (LA_SPLIT, prev-pinned advance)

C-source **cannot** reach:
- gcc's prologue/epilogue ordering decisions
- gas `.set reorder` conservative behavior
- splat/linker output
- mid-function regalloc dual-allocation
- cross-function shared-epilogue fall-through

Cookbook "no C fix" claims were wrong 3× (retired §8.6, §8.11, §8.14)
and correct 5× (confirmed intractable). Worth attempting before trusting
a "no C fix" claim.
