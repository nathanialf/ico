## Patterns to recognize for future matches

C-reachable (these techniques have worked):
- **goto-end** fuses multiple `return 0;` paths → §8.3 retired
- **`*(volatile T *)&`** on adjacent stores forces source order → §8.17 retired
- **`LA_SPLIT(reg, sym)`** macro with inner `KEEP_LIVE` for sd-ra interleave → §8.9 retired
- **`ADDU_RT(dst, src)`** macro (inline asm `+r` tied) for commutative addu rd==rt → §8.11 retired
- **prev-pinned advance** + `NOP()` for linked-list dual-delay-slot loops → §8.14 retired
- **goto-loop** with `{call_arg=...; advance; func(...);}` block for jal-delay choice → 00A3A0 retired
- **Pre-pin FP args + KEEP_LIVE_FP** before volatile reload → 1356D0 retired
- **`-fno-schedule-insns` per-file cflag** for bne→beql+delay-store → 0D4E30 retired
- **Cookbook "no C fix" claims are sometimes wrong** (§8.6, §8.11, §8.14 retired despite the claim)

C-NOT-reachable (15+ documented intractable):
- gcc-owned prologue/epilogue ordering (most multi-line prologue reorders)
- gas `.set reorder` refusing certain delay-slot fills
- gcc regalloc rigidity (dual-pinning the same register across non-overlapping live ranges)
- splat-emitted output (la pseudo, bare-paren gp_rel)
- cross-function fall-through (shared epilogues, switch jump tables)
