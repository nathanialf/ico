## How the prototype differs from PAL's build

This branch is `main`'s PAL source with the prototype's differences, most of
them reached through the June 26, 2001 demo (`jun26`) and the USA build
(`ntsc`), the two builds either side of it. The debug menu's `DISC VER.`
line (`debug.c`) dates the prototype `Aug  7 2001 15:03:20` and PAL's
`Jan 17 2002 15:37:26`. Each line names where the difference lives; the
comment at that place has the detail.

Disc and video mode:

- `SYSTEM.CNF` reads `VER = 1.00` and `VMODE = NTSC`; `systemStatus`
  starts at 0 in `main.c` (PAL 1), and the movie buffers are sized for a
  720 x 480 picture (`mv_vobuf.h`; PAL 720 x 576).
- The five VU1 programs' constant-address overlays hold the byte 0x6E
  (PAL zero): `overlay-fill=110` on each `.dsm` line of
  `config/link_order.aug6.txt` (`BUILDING.md`).

Data and records:

- The link has the 70 data-only members PAL's has; PAL's hint table,
  `motSyncPairs` and subtitle file names are not in it, and no code here
  reads one. Most tables hold fewer rows, and ten record types have another
  layout; each row of `config/data_members.aug6.txt` says how its member
  compares with PAL's.
- `charFileName.h`'s `MAX_CHARS` is 1576 (PAL 1637).
- The engine's records (`Act`, `Sub15C`, `ActWork` and others) have the
  prototype's layout in their owner headers; the comment at each field gives
  its offset and the code that reads it.

Code this build lacks:

- Sony's `libscf`, and `sugipon`'s `puddle.c`, `waterDot.c` and
  `windmill.c`, are not in the link, nor is the hint system; many smaller
  functions of the stage scripts and the action layer were added after
  August 6.
- `subGirlControl`'s slow-walk debug display, compiled out of every retail
  build, stands as a draft whose statements the ROM does not decide (the
  README's Status section).
