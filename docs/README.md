## How the Asian build differs

This branch is the `kor` branch's source (the Korean build, which is the
`jpn` branch's source with the Korean differences) with the Asian build's
differences. The debug menu's `DISC VER.` line (`debug.c`) dates the Asian
build `Nov  2 2001 19:35:51`, the Japanese one `Nov  2 2001 17:26:01` and
the Korean one `Jan  9 2002 19:03:40`. [`TARGETS.md`](TARGETS.md) lists each
difference and where it lives: the disc's ids, the Japanese layout property
table (412 rows) and the ids that follow from it, and the Japanese `pad.c`.
Everything else, including the Korean DVD `cdvd.c`, the data archive's
offset, the two prints, the removed store and the link order, is as in the
Korean build.

## Local files that are not part of the repository

A maintainer's checkout may also hold `NOTES.md`, `COOKBOOK.md`,
`MATCH_VU.md`, `MATCHING_NOTES.md`, `ARCHIVE_retired_notes.md` and
`pal_source_tree.{md,json}` here: notes on the compiler's and assembler's
behaviour and a census of the disc's listing. They are gitignored, nothing
in the build reads them, and nothing in the repository depends on them.
