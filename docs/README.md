## How the Korean build differs

This branch is the `jpn` branch's source (the Japanese build, which is
`main`'s PAL source with the Japanese differences) with the Korean build's
differences. The debug menu's `DISC VER.` line (`debug.c`) dates the Korean
build `Jan  9 2002 19:03:40`, the Japanese one `Nov  2 2001 17:26:01` and
PAL's `Jan 17 2002 15:37:26`. [`TARGETS.md`](TARGETS.md) lists each
difference and where it lives: the disc's ids, the layout property table's
six missing rows and the ids that follow them, PAL's DVD `cdvd.c` and
`pad.c`, the data archive's offset on the Korean disc, two prints and one
removed store, and three objects that link in PAL's places. Everything
else, including every difference of the Japanese build from PAL's (`main`'s
`docs/TARGETS.md`), is as in the Japanese build.

## Local files that are not part of the repository

A maintainer's checkout may also hold `NOTES.md`, `COOKBOOK.md`,
`MATCH_VU.md`, `MATCHING_NOTES.md`, `ARCHIVE_retired_notes.md` and
`pal_source_tree.{md,json}` here: notes on the compiler's and assembler's
behaviour and a census of the disc's listing. They are gitignored, nothing
in the build reads them, and nothing in the repository depends on them.
