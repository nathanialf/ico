## How the USA build differs from PAL's

This branch is `main`'s PAL source with the USA build's differences. The
debug menu's `DISC VER.` line (`debug.c`) dates the USA build
`Aug 20 2001 22:01:44` and PAL's `Jan 17 2002 15:37:26`. Each line names
where the difference lives; the comment at that place has the detail.

Disc and video mode:

- `SYSTEM.CNF` reads `VER = 1.00` and `VMODE = NTSC`; `systemStatus`
  starts at 0 in `main.c` (PAL 1), and the movie buffers are sized for a
  720 x 480 picture (`mv_vobuf.h`; PAL 720 x 576).
- The five VU1 programs' constant-address overlays hold the byte 0x6E
  (PAL zero): `overlay-fill=110` on each `.dsm` line of
  `config/link_order.ntsc.txt` (`BUILDING.md`).

Data and records:

- The link has 71 data-only runs: PAL's hint table and subtitle file names
  are not in it, and no code here reads either. Most tables hold fewer rows,
  and eight record types have another layout; each row of
  `config/data_members.ntsc.txt` says how its member compares with PAL's.
- `charFileName.h`'s `MAX_CHARS` is 1582 (PAL 1637).
- Records with another layout (`Act`, `ActWork`, `MotionDef`, `TexRec`,
  `PObjMdl`, `McProductFile` and others) are in `HEADERS.md`.

Code this build lacks, or has only here:

- Absent: Sony's `libscf`; `sugipon`'s `puddle.c`, `waterDot.c` and
  `windmill.c`; the hint system (`Hint_Init`, `MakeHintSaveInfo`,
  `ReadHintSaveInfo`, `FinishHint`, `actGirlHintVoice`); and many smaller
  functions of the stage scripts and the action layer.
- Only here, among others: `actBoyItem`, `afterCommonItem`,
  `actSt17bIntro`, `actSt47aSekizo3` and `actSt47aSekizo4`, which the
  August 6, 2001 prototype's `TRFILE.TXT` and `MAIN.MAP` name and PAL's
  `TRFILE.TXT` does not, and `bga_updateMotionFrame` (`BgAnimation.c`, a
  derived name).

## Local files that are not part of the repository

A maintainer's checkout may also hold `NOTES.md`, `COOKBOOK.md`,
`MATCH_VU.md`, `MATCHING_NOTES.md`, `ARCHIVE_retired_notes.md` and
`pal_source_tree.{md,json}` here: notes on the compiler's and assembler's
behaviour and a census of the disc's listing. They are gitignored, nothing
in the build reads them, and nothing in the repository depends on them.
